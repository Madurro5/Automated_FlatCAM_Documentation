    Automated FlatCAM¶

    Rôle¶

    FlatCAM est le logiciel choisi pour convertir les fichiers Gerber exportés depuis KiCad en fichiers d'usinage G-code contenant des commandes exploitables par le contrôleur de la CNC.

    Extrait de flatcam.org

    PCB milling, also known as mechanical etching, is the fastest, cleanest, high-performance and economical PCB prototyping process today. FlatCAM : FlatCAM lets you take your designs to a CNC router. You can open Gerber, Excellon or G-code, edit it or create from scratch, and output G-Code. Isolation routing is one of many tasks that FlatCAM is perfect for. It is open source, written in Python and runs smoothly on most platforms. Check out the features list. FlatCAM is open source and it has a public repository

    Source : FlatCAM et Developing FlatCAM (consulté le 10 avril 2026)

    Ce logiciel est très complet et demande un certain temps de prise en main. Automated FlatCAM est un fork de FlatCAM. Il a été réalisé pour apporter des modifications au logiciel, en automatisant et en simplifiant la conversion de Gerber vers G-code.

    Installation du logiciel¶

    L'installation du logiciel Automated FlatCAM s'effectue à l'aide de l'installateur Automated_FlatCAM_Setup_8.994.exe qui vous a été fourni avec cette documentation ou qui est téléchargeable (ici)[].

    L'installateur n'installe que la version opérationnelle de FlatCAM Automatisé (Automated FlatCAM) sous forme d'une application exécutable.

    Si vous souhaitez installer le code de FlatCAM Automatisé pour y apporter des modifications ou pour d’autres raisons, veuillez vous référer à la page Installation du code.

    Prérequis¶

    Automated FlatCAM (fork de FlatCAM) a été développé et testé uniquement sur Windows 10 et Windows 11. Bien que FlatCAM soit compatible avec Linux, l'installateur fourni ne permet d'installer Automated FlatCAM que sur Windows.

    Fonctionne sur les configurations suivantes :

    Étapes d'installation¶

    Lancez l'exécutable et suivez les étapes suivantes.

    Suivez les instructions de l’installateur.

    Seules les versions française et anglaise sont complètes pour cette version de FlatCAM.

    L’assistant d’installation démarre. Appuyez sur Suivant.

    Chemin d'installation du logiciel : laissez le chemin par défaut proposé et appuyez sur Suivant.

    Cliquez sur Suivant.

    Vous avez la possibilité de créer un raccourci sur le bureau (coché par défaut). Si cette installation est la seule version de FlatCAM sur votre machine, vous pouvez également cocher la deuxième option. Les extensions de fichiers .FlatPrj seront associées à cette application.

    Appuyez sur Suivant.

    Cliquez sur Installer pour lancer l'installation.

    Automated FlatCAM est en cours d'installation...

    L'installation est terminée. Vous pouvez fermer l'installateur et lancer FlatCAM via le raccourci sur le bureau ou le menu Démarrer.

    Note : Vous pouvez également désinstaller proprement le logiciel. Un désinstallateur (uninstaller) est créé par l'installateur.
